Funktionen

Alles, was eine 3D-App im Web braucht

Veldara ist nicht bloß eine Render-Schicht. Es ist ein vollständiges Ökosystem — vom Prototyp bis zum produktionsreifen Erlebnis.

Deklarative Szenen

Beschreiben Sie die 3D-Szene als Komponenten — Veldara verwaltet den Lebenszyklus der Three.js-Objekte, Sie konzentrieren sich auf das Erlebnis.

Physik inklusive

Physik-Engine auf Rapier-Basis mit erstklassiger Integration: Kollisionen, Constraints und Starrkörper in wenigen Zeilen.

XR-Unterstützung

VR- und AR-Erlebnisse aus derselben Codebasis. Die volle Kraft von WebXR, ohne Boilerplate.

Animations-Werkzeuge

Springs, Timelines und scroll-gesteuerte Animationen mit deklarativer API — Bewegung als natürlicher Teil der Szene.

Modelle laden

GLTF-, DRACO- und KTX2-Unterstützung mit automatischem Caching und Suspense — Modelle erscheinen einfach.

3D-Layout

Ein Flexbox-artiges Layout-System im Raum — Objekte ausrichten, anordnen und skalieren wie ein UI.

Entwicklererlebnis

Code, den man gerne schreibt

Keine imperative Szenenverwaltung, kein manuelles Aufräumen. Sie schreiben Komponenten, Veldara rendert sie — reaktiv.

  • Vollständige TypeScript-Unterstützung mit automatischer Typinferenz
  • Hot Module Replacement — der Szenenzustand überlebt das Neuladen
  • Jedes Three.js-Objekt bleibt direkt zugänglich, wenn Sie tiefer wollen
Szene.svelte 
<script>
  import { T, useTask } from '@veldara/core'

  let forgas = $state(0)
  useTask((delta) => { forgas += delta })
</script>

<!-- Egy forgó kocka, ennyi az egész -->
<T.Mesh rotation.y={forgas}>
  <T.BoxGeometry />
  <T.MeshStandardMaterial color="#2C5C88" />
</T.Mesh>
